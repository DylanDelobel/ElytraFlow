# Changelog

## [1.3.0] - 2026-09-25

### Changed
- Updated to Minecraft 26.3 (Fabric Loader 0.19.5, Fabric API 0.161.0+26.3, NeoForge 26.3.0.16-beta).
- New mod icon, now also shown in the NeoForge mod list.

## [1.2.0] - 2026-06-17

### Changed
- Updated to Minecraft 26.2 (Fabric Loader 0.19.3, Fabric API 0.152.1+26.2, NeoForge 26.2.0.1-beta).

## [1.1.0] - 2026-05-18

### Added
- NeoForge support. Separate Fabric and NeoForge jars are now built from a single codebase.

## [1.0.0] - 2026-04-26

### Added
- Initial release.
- Automatic chestplate re-equip on landing — scans the full inventory and equips the best available chestplate when the player touches the ground while wearing an elytra.
- Items with Curse of Binding are always excluded from selection.
- Toggle keybind (unbound by default) under Options → Controls → ElytraFlow to enable or disable the mod at any time.
